These will guide the next round of refinements to the system.



1\. General Settings and Permissions

Clarify the purpose of the country selection options in the system.



Restrict employee and worksite import/export functionality to Admin and Engineer roles.



Support importing boundary polygons along with master data.



Restrict visibility of budgets, costs and all price-related information to Admin users.



2\. Employee Management

Make Grade Code and Designation selectable from dropdowns populated with the unique values already available in the system. Apply this consistently wherever these fields are used.



Include salary structure details directly in the employee creation modal.



Allow editing of Staff Grade Description, Grade Code and Driver status, while maintaining their respective change histories.



For Supervisors, Superintendents and Engineers, the Staff Grade Description should either be hidden or made non-editable to prevent inconsistencies.



Display a confirmation dialog when modifying employee reporting hierarchies.



3\. Worksite and Accommodation Management

Make Group and Zone selectable from dropdowns, with an option to select "Other" and enter a new value. Newly added values should become available for future selections.



Add an option to locate the current position when drawing worksite boundaries on the map.



Provide a search option when drawing accommodation boundaries, similar to the existing worksite boundary editor.



Allow Job Items to be created directly within the Worksite Creation modal.



Provide editing, deactivation and related management options for accommodations.



Allow multiple Supervisors to be assigned to a worksite. Supervisors should only see their assigned worksites and the workers belonging to those worksites. Superintendents and Engineers should have visibility of the entities under their respective reporting scope.



Include Job Item details in worksite exports.



4\. Mobile Application

Ensure that changes to scheduled working days, including removed working days, are synchronised and reflected in the mobile application.



Make the location ping interval configurable through Company Settings.



5\. Leave Management

Ensure that extra staff assignments also display the appropriate leave-related assignment label, consistent with base-planned assignments.



Do not display weekly-off-day mismatch warnings when the assigned date is not affected by the mismatch.



Exclude workers who are already assigned or currently on leave from the cover-worker selection dropdown.



Introduce dashboard alerts for pending cover-worker assignments.



6\. Operational Planner

Provide import and export options for Job Item assignments.



7\. User Management

Resolve the account-lockout issue where a user whose default password was not changed within the permitted period remains unable to log in even after an Admin password reset.



Display the user's name alongside their account details on the Users page.



8\. Dashboard and Navigation

Improve the menu structure by organising related pages under clear sub-listings.



Clean up the dashboard by grouping related alerts, notifications and pending actions into appropriate categories.



9\. Salary Structure

Add sorting functionality to the Salary Structure page.



Allow future salary revisions to be edited or deleted from the revision history modal.



Display the complete salary and cost breakdown directly in the Salary Structure, including:



Basic Salary



Special Allowance



Fixed OT



Bonus



Telephone Allowance



HRA/Transport



Total Salary Portion



Gratuity, calculated as (Basic Salary / 365) × 30



Leave Salary, calculated as Basic Salary / 12



Per-month provision, including the applicable fixed provisions configured in Company Settings, along with gratuity and leave salary



Total Staff Cost



HR Overhead



Final Cost



Standard working hours



Break information



10\. Payroll

Incorporate the salary revision code into the Grade Code to distinguish salary revisions. For example, Grade Code G3C under the 2026 revision should appear as G3C-2026, while the same grade under the 2027 revision should appear as G3C-2027.



11\. Live Map

Resolve the issue where workers who are scheduled are displayed as "Not Scheduled".
