---
name: write-adr
description: Use when a technical or design decision is made or changed. Records context, options, decision, reasoning and consequences as an Architecture Decision Record.
---
Create `docs/decisions/NNN-short-title.md` (next number in sequence) with these sections:
Status (Proposed / Accepted / Superseded by NNN), Date, Context, Options considered, Decision, Why, Consequences.
Keep it under one page. Link related ADRs and the docs it affects. Add a line to the index in `docs/decisions/README.md`.
If the decision resolves an item in `docs/decisions/decision-register.md`, update that item's status and link the ADR.
