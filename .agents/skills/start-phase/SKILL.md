---
name: start-phase
description: Use at the start of a conversation to begin work on a numbered development phase. Loads only that phase's context, asks questions, and produces a plan for approval.
---
1. Open `docs/phases/PHASE-NN-*.md` for the requested phase and the phase index `docs/phases/README.md` (check its dependencies are done).
2. Read only the files in the phase's Context section plus `AGENTS.md` and `.agents/rules/*`.
3. Summarise in a few lines what you will build and what is out of scope.
4. Ask up to 10 questions about anything unclear or contradictory (most important first). Wait for answers.
5. Write the plan: files to create or change, order, how each checklist item will be verified. Wait for approval before writing any file.
